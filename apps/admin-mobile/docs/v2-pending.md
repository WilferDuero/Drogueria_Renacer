# Pendientes para Version 2

1. Flujo de pedidos con detalle item a item (aceptacion parcial y motivo rechazo persistente).
2. Registro de ventas asistido desde pedido aceptado (sin captura manual de JSON).
3. Soporte offline-first con cola de reintentos por modulo.
4. Auditoria de acciones admin (quien hizo que, cuando).
5. Paginacion y virtualizacion para listados grandes.
6. Filtros avanzados (rango fecha, categoria, vendedor, estado combinado).
7. Dashboard con tendencias (diario/mensual/anual) y alertas de stock bajo.
8. Hardening adicional de seguridad (biometria opcional para reentrada, bloqueo por inactividad).
9. Plantillas configurables de WhatsApp (mensajes editables por negocio).
10. Migracion a New Architecture de React Native (actualmente Legacy Architecture).
11. Mejoras de push: preferencias por usuario, horario silencioso y deduplicacion avanzada.
