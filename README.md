# 💊 Droguería Renacer — Plataforma Web de Ventas y Pedidos

Proyecto de desarrollo de software orientado a digitalizar
la consulta de productos y la gestión de pedidos de una droguería.

El sistema incluye una interfaz web para clientes, componentes
administrativos y una estructura para aplicación móvil.

## 🚀 Características principales

- Catálogo de productos organizado por categorías.
- Carrito de compras para seleccionar productos.
- Registro y consulta de pedidos.
- Estados de pedidos: pendiente, aceptado, rechazado y cancelado.
- Comunicación y coordinación de pedidos mediante WhatsApp.
- Interfaces para administración del sistema.
- Componentes para integración con servicios backend.

## 🛠️ Tecnologías

Lenguajes presentes en el repositorio:

- JavaScript
- TypeScript
- HTML5
- CSS3

## 📂 Estructura del proyecto

- `apps/admin-mobile/`: componentes de aplicación móvil.
- `server/`: código del servidor.
- `js/`: archivos JavaScript.
- `docs/`: documentación.
- `index.html`: interfaz web principal.
- `admin.html`: interfaz administrativa.
- `style.css`: estilos de la aplicación.

## 📌 Estado del proyecto

Proyecto desarrollado como solución tecnológica para un
negocio real, con versión web desplegada para demostración.

No fue implementado como sistema comercial operativo
en la droguería.

Este repositorio es independiente de mi aplicación de
escritorio para el control de inventarios y vencimientos.
